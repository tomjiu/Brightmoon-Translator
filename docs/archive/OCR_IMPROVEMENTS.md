# OCR 界面优化方案

## 问题分析

1. **闪烁问题**：定时刷新导致整个界面重绘
2. **工具栏变形**：工具栏跟随窗口缩放，在小窗口时按钮挤压变形
3. **文字可选中**：已实现（select-text），但需要确保更新时不闪烁

## 解决方案

### 1. 工具栏独立布局（优先级最高）

**当前问题**：
- 工具栏和 OCR 内容在同一个窗口内
- 窗口缩小时，工具栏按钮被挤压变形

**解决方案**：
- 工具栏应该是**独立的固定高度区域**（32px）
- 使用 `fixed` 定位，始终在顶部
- 工具栏内容使用 `flex-shrink-0` 防止收缩
- 按钮只显示图标，用 tooltip 说明功能
- 语言选择器使用最小宽度（60px）并允许滚动

**布局结构**：
```
┌─────────────────────────────────────┐
│ 工具栏（固定 32px 高度）              │ ← fixed, 不受窗口大小影响
├─────────────────────────────────────┤
│                                     │
│   OCR 翻译内容区域                   │ ← 可以任意缩放
│   （截图背景 + 翻译文字覆盖）         │
│                                     │
└─────────────────────────────────────┘
```

### 2. 减少闪烁（内容变化检测）

**当前实现**：
- 已有内容变化检测（第186-191行）
- 使用 `requestAnimationFrame` 批量更新（第211行）
- 直接更新 img src 而不触发 React 重渲染（第202-208行）

**改进**：
- ✅ 保持现有的变化检测逻辑
- ✅ 只在文本真正改变时更新
- 增强：为翻译文字层添加 `will-change: contents` CSS 提示

### 3. 文字可选中（已实现）

**当前状态**：
- TranslationLine 组件第81行：`select-text cursor-text`
- 源文本第608行：`select-text cursor-text`
- 后备翻译第594行：`select-text cursor-text`

**验证**：功能已实现，用户应该可以直接选中并复制文字

2. **P1** - CSS 优化减少重绘（will-change, transform）
3. **P2** - 验证文字选中功能是否正常工作
