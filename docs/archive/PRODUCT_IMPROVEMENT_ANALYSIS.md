## 一、UI/UX问题

### 1.1 配色问题（低优先级）
**现状**: 暗黑模式配色感觉老土
**评估**: 小问题，随时可改
**建议**: 
- 参考现代设计趋势（VS Code, GitHub Dark, Nord等主题）
- 提供多套暗色主题选择
- 优先级：P3

### 1.2 布局和功能分类混乱 ⚠️ 重要
**问题**: 
1. 浏览器扩展功能出现在桌面软件界面
   - 粘贴板监听 ✅ (桌面需要)
   - 追加模式 ❓ (可能是浏览器特有)
   - 双语对照 ✅ (桌面需要)
   - 行间模式 ❓ (可能是浏览器特有)

**解决方案**:
- 区分桌面版和浏览器版特有功能
- 创建功能-平台映射表
- 根据运行环境动态显示/隐藏功能

**优先级**: P1

### 1.3 设置页面混乱 ⚠️ 重要
**问题**:
- 中英文设置混杂
- 缺少清晰的分类
- TTS设置和语音识别未实现

**解决方案**:
- 重新组织设置页面结构
- 统一语言（全中文或全英文+翻译）
- 补全缺失功能或移除占位

**优先级**: P1

## 三、词典/生词本重新设计 ⭐ 核心改进

### 3.1 当前问题
**现状**: 简单的生词本功能
**不足**: 缺少学习辅助功能

### 3.2 目标愿景：智能词典学习系统

#### 核心功能
1. **多源词典集成**
   - 导入牛津词典
   - 导入有道词典
   - 集成Webster、Cambridge等
   - API对接（有道、扇贝等）

2. **AI增强学习**
   - 基于词根的关联学习
   - 情景化例句生成
   - 学习关系网构建
   - 历史翻译文本库关联

3. **记忆优化**
   - 遗忘曲线算法（Ebbinghaus）
   - 间隔重复系统（Spaced Repetition）
   - 个性化复习计划
   - 记忆强度追踪

4. **本地小型模型辅助**
   - 词义解释
   - 例句生成
   - 近义词推荐
   - 使用场景说明

#### 数据结构设计
```typescript
interface VocabularyEntry {
  word: string;
  
  // 多源词典数据
  definitions: {
    source: 'oxford' | 'youdao' | 'webster' | ...;
    partOfSpeech: string;
    meaning: string;
    examples: string[];
  }[];
  
  // AI增强数据
  aiAnalysis: {
    etymology: string;          // 词源/词根
    relatedWords: string[];     // 关联词
    contextualUsage: string[];  // 情景用法
    mnemonics: string;          // 记忆技巧
  };
  
  // 学习数据
  learning: {
    firstSeen: Date;
    lastReviewed: Date;
    nextReview: Date;
    reviewCount: number;
    memoryStrength: number;     // 0-100
    mistakes: number;
    sourceContext: {            // 来源上下文
      text: string;             // 原文
      translation: string;      // 译文
      source: string;           // 来源（浏览器/PDF等）
      date: Date;
    }[];
  };
}
```

## 五、浏览器-桌面联动 ⭐ 核心改进

### 5.1 目标愿景
**定位**: 本地语言学习的翻译软件
**核心**: 浏览器扩展 + 桌面软件深度集成

### 5.2 功能需求

#### 5.2.1 页面内容保存
**场景**: 用户在浏览器阅读英文文章
**功能**:
- 扩展读取页面内容
- 保存到桌面软件的学习语料库
- 自动提取关键词汇
- 关联到词典学习系统

**技术方案**:
```typescript
// 浏览器扩展
browser.runtime.onMessage.addListener((msg) => {
  if (msg.action === 'savePage') {
    const pageContent = {
      url: window.location.href,
      title: document.title,
      content: extractMainContent(),
      language: detectLanguage(),
      vocabulary: extractKeywords(),
      timestamp: Date.now(),
    };
    
    // 发送到桌面应用
    sendToDesktopApp(pageContent);
  }
});

// 桌面应用接收
app.listen('browser-save-page', (data) => {
  corpus.add(data);
  vocabulary.extractAndSave(data.vocabulary);
});
```

#### 5.2.2 快速保存到生词本
**触发方式**:
1. 浏览器扩展：选中单词 → 右键菜单 → "添加到生词本"
2. 桌面软件：翻译结果 → 单词点击 → "添加到生词本"
3. 剪贴板监听：识别到单词 → 自动提示保存

**交互设计**:
```
方式1: 右键菜单
  选中单词 → 右键 → "Add to Vocabulary" → 保存

方式2: 浮动按钮（有道风格）
  选中单词 → 出现小图标 → 点击 → 显示简明解释 → "保存"按钮

方式3: 剪贴板智能识别
  复制单词 → 桌面弹出通知 → "这是一个单词，要加入生词本吗？"
```

#### 5.2.3 选中文字浮动操作（有道风格）
**实现原理**:
- 监听文本选择事件（`selectionchange`）
- 获取选中文本和位置
- 显示浮动工具栏

**功能按钮**:
- 📖 翻译
- ⭐ 加入生词本
- 🔊 朗读
- 📋 复制

**技术方案**:
```typescript
// 监听选中事件
document.addEventListener('mouseup', () => {
  const selection = window.getSelection();
  if (selection && selection.toString().trim()) {
    const rect = selection.getRangeAt(0).getBoundingClientRect();
    showFloatingToolbar({
      text: selection.toString(),
      x: rect.left,
      y: rect.top - 40, // 上方显示
    });
  }
});
```

**优先级**: P0 (核心价值)
