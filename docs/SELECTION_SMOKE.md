# Desktop 取词 Smoke Checklist

在 `pnpm tauri dev` 下逐项验证。每次发布前全跑一遍。

## 1. 基础取词

| # | 操作 | 预期 | 验证 |
|---|---|---|---|
| 1.1 | 浏览器选中文本 | 浮钮弹出，文本与选区一致 | ☐ |
| 1.2 | 编辑器（记事本/VSCode）选中文本 | 浮钮弹出，文本与选区一致 | ☐ |
| 1.3 | 终端（Windows Terminal/cmd）选中文本 | 浮钮弹出（走 UIA，不触发 Ctrl+C SIGINT） | ☐ |
| 1.4 | Electron 应用（Slack/Discord）选中文本 | 浮钮弹出，文本与选区一致 | ☐ |
| 1.5 | 空选区（点击空白区） | 无弹窗、无翻译 | ☐ |
| 1.6 | 单选一个字母/汉字 | 浮钮弹出，取词正确 | ☐ |

## 2. Pop 按钮

| # | 操作 | 预期 | 验证 |
|---|---|---|---|
| 2.1 | 选中文本后点击浮钮「译」 | 弹出翻译卡片，译文正确 | ☐ |
| 2.2 | 5 秒不点击浮钮 | 浮钮自动消失 | ☐ |
| 2.3 | 浮钮存在时点击浮钮外任意处 | 浮钮消失 | ☐ |
| 2.4 | 选中后按键盘 | 浮钮消失，不弹出翻译 | ☐ |
| 2.5 | 浮钮弹出后再次选中不同文本 | 新浮钮弹出，旧浮钮消失，取新文本 | ☐ |

## 3. 翻译卡片（MT overlay）

| # | 操作 | 预期 | 验证 |
|---|---|---|---|
| 3.1 | Pop 点击后翻译卡片出现 | 卡片不溢出屏幕、不裁切 | ☐ |
| 3.2 | CJK 译文 | 卡片宽度足够不横向截断 | ☐ |
| 3.3 | 鼠标离开卡片 120ms | 卡片自动消失 | ☐ |
| 3.4 | 热键翻译（默认 Ctrl+Shift+Y） | 翻译卡片出现在光标处 | ☐ |

## 4. 悬停取词（hover dictionary）

| # | 操作 | 预期 | 验证 |
|---|---|---|---|
| 4.1 | 鼠标悬停英文单词 350ms+ | 词典卡片弹出 | ☐ |
| 4.2 | 鼠标悬停中文词语 350ms+ | 词典卡片弹出 | ☐ |
| 4.3 | 悬停在窗口标题栏/chrome | 不弹出卡片 | ☐ |
| 4.4 | 悬停在可编辑文本区域 | 不弹出卡片（不干扰打字） | ☐ |
| 4.5 | 键盘输入后 1.5 秒内悬停 | 不弹出卡片 | ☐ |
