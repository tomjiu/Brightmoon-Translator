## 🚀 如何使用

### 1. 启动应用
开发服务器已启动，应该会自动打开 Tauri 窗口。

如果没有自动打开：
```bash
cd E:/Code/ai/moontranslator
pnpm tauri dev
```

### 2. 初始化数据（首次使用）
```bash
cd src-tauri
cargo run --example data_init_demo
```

这将导入：
- 15,000 核心高频词
- 70,000+ 词根数据

### 3. 配置 LLM
在应用设置中配置 OpenAI 兼容的 API。

### 4. 使用功能

#### 浏览词库
1. 点击侧边栏的 📖 **Vocabulary** 图标
2. 选择 **AI Learning** 标签
3. 点击 **Browse Vocabulary**
4. 浏览 15,000 核心词库，按词频排序

#### 学习新词
1. 搜索或选择单词
2. 系统自动创建卡牌
3. AI 生成词源、助记法、例句
4. 查看学习内容

#### 复习卡牌
1. 点击 **Review** 按钮
2. 显示待复习卡牌数量
3. 问答模式复习
4. 4级评分（Again/Hard/Good/Easy）
5. 自动调度下次复习

#### 查看统计
1. 点击 **Statistics**
2. 查看学习进度
3. 会话统计
4. 正确率分析
